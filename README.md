# 台電全台灣電桿圖資與巡檢系統 (Taipower Taiwan Equipment Map)

本專案為獨立於特定縣市的「全台灣電桿設備圖資系統」，專門設計用於乘載 **全台灣 315 萬+ 支台電電桿開放資料 (Dataset 33305)**，並維持秒級流暢操作與巡檢功能。

---

## 專案特色

1. **大數據載入架構**：採用 PMTiles 向量圖磚與縣市分區動態切片，擺脫單一巨大 JSON 造成的瀏覽器記憶體崩潰問題。
2. **零雲端成本 (Serverless)**：支援靜態託管（GitHub Pages），免租用高額雲端空間伺服器。
3. **保留現場巡檢核心能力**：
   - 點擊電桿查看中文桿名（桿號）、圖號座標與行政區
   - 一鍵開啟外部導航（Google Maps / Apple Maps）
   - 現場拍照、照片浮水印與 IndexedDB 離線安全存檔
   - 瑕疵不良記錄與備份匯出

---

## 資料來源

- **政府資料開放平臺**：[台灣電力公司_電桿坐標及桿號 (Dataset 33305)](https://data.gov.tw/dataset/33305)
- **總資料量**：全台灣約 315 萬 ~ 320 萬筆電桿
- **主要欄位**：縣市、行政區、鄉里、圖號座標、形式、桿號（中文桿名）、TWD_97_X、TWD_97_Y
